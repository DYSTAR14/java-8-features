## Tip: how to read Javadoc quickly

1. Open the class page (for example `Stream`).
2. Use the **"Method Summary"** table at the top. Click the tabs "Instance Methods" / "Static Methods".
3. Read the one-line description, then click the method name for details and examples.
4. The text at the top of the package page (`java.util.stream`) explains the concepts: **read it twice**.

> Note: some pages move over time on Oracle's website. If a link is broken, search the title on <https://docs.oracle.com/javase/8/docs/>.
